# Muhammad Farhan Siddiqui — React Portfolio

Premium finance portfolio built with React 19, Vite, Tailwind CSS, Framer Motion, React Icons and AOS.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to GitHub Pages
The Vite base is already set to `/Farhan-Siddiqui/`.
```bash
npm install
npm run deploy
```
Commit the project to the `Farhan-Siddiqui` repository before deploying.

## Automatic GitHub Pages deployment
A GitHub Actions workflow is included. Push the project to the `main` branch, then in repository **Settings → Pages**, set Source to **GitHub Actions**.
